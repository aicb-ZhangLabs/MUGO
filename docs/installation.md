# Installation

The paper reproduction scripts are run directly from the repository.

```bash
git clone https://github.com/aicb-ZhangLabs/MUGO.git
cd MUGO
pip install -e .
```

Core requirements:

- Python >= 3.8
- PyTorch >= 2.0
- pandas
- numpy
- pyfaidx
- borzoi-pytorch

For the full paper pipeline, also install the analysis and optional backbone
dependencies described in the root `README.md`.
